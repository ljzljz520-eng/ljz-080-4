# 🏗️ 工擎云护 · 工程机械保养派单系统

面向工程机械租赁公司的设备保养/故障智能派单平台：租赁设备（挖机、吊车、压路机）
回传**小时数、故障码、所在工地**，系统按**保养周期 + 故障严重度 + 就近原则**自动派单；
技师在手机端完成接单/到场/完工，填报**用料、照片、停机时长**；客户在线**确认是否恢复作业**。
外勤页面支持**离线填报、联网自动补传**。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 📊 调度台 `/` | 设备/技师/工单看板、高危故障、待派单与待确认清单、一键扫描派单 |
| 🚜 设备台账 `/machines` | 遥测数据、保养周期进度条、故障码、附近技师评分、手动派单、历史工单 |
| 📋 工单 `/orders` | 全生命周期跟踪：派单候选排序、时间线、完工报告、改派 |
| 👷 技师 `/technicians` | 技能机型（挖机/吊车/压路机）、值班开关、实时位置、负载 |
| 📱 技师外勤 `/field` | **移动端页面**：接单→出发→到场→完工；用料/拍照/停机时长；**离线可填** |
| ✅ 客户确认 `/client` | 查看诊断、用料、照片、停机时长 → 确认恢复作业或要求返工 |
| 📡 租赁同步 `/sync` | 遥测 upsert 接口联调表单，含三机型批量模拟回传 |

## 派单规则（`server/rules.js` / `server/dispatch.js`）

- **周期保养**（距上次保养小时到期即触发）
  - 挖机：250h 一级 / 500h 二级 / 1000h 大保养
  - 吊车：200h / 400h / 800h 大保养
  - 压路机：200h / 400h / 600h 大保养
- **故障码**：E101 机油压力低（高危，立即停机）、C402 制动磨损、E305 回油滤芯堵塞等，按 critical/high/medium/low 分级
- **技师评分**：机型技能匹配为前提；距离分（每公里 −1.1）+ 在线 +15 + 空闲负载 + 高危加急 +10 + 全能机型 +5
- **在线优先**：高危及常规派单优先指派在线技师；离线技师仅在无在线候选时兜底
- 候选技师排序、评分与理由随工单留存，支持调度员**改派**

## 离线方案（外勤核心）

1. **Service Worker（`public/sw.js`）**：缓存应用外壳与构建产物，无网也能打开外勤页面；已上传照片 SWR 缓存
2. **IndexedDB 快照层（`src/lib/idb.ts`、`api.ts`）**：工单/设备/看板 GET 成功后存快照，断网自动回退本地缓存
3. **发件箱 Outbox**：离线时点接单/出发/到场/提交完工，先写入 IndexedDB 队列；恢复网络自动补传（重试计数、错误留存），顶栏实时显示待发条数
4. **完工草稿**：诊断、用料、停机时长、照片输入即自动保存；照片经 Canvas 压缩（≤1280px/JPEG）后以 base64 随单补传，避免大图撑爆配额
5. 页面顶部离线黄条明确提示当前为离线模式

## 技术栈

- 后端：Node.js + Express，JSON 文件持久化（`server/data/db.json`，零外部依赖即可运行），照片落盘 `server/data/uploads`
- 前端：React 18 + TypeScript + Vite，hash 路由，无 UI 框架依赖的响应式样式（移动端优先）
- PWA：manifest + Service Worker，可"添加到主屏幕"

## 快速开始

```bash
npm install
npm run dev        # 后端 http://localhost:4000 ，前端 http://localhost:5173 （/api 已代理）

# 或生产模式（后端同时托管构建产物）
npm run build
npm start          # 打开 http://localhost:4000

npm run seed       # 重置演示数据（5 台设备 / 5 名技师 / 4 个工地）
```

## 演示路径建议

1. 调度台看到 4 台待派单设备（含 1 台 E101 高危吊车）→「立即扫描派单」
2. 工单详情查看候选技师距离/评分与派单时间线
3. 技师外勤切换到 **张师傅** 接单 → 出发 → 到场，填写用料、拍照、停机时长后提交
4. 客户确认页查看报告与照片 → 「确认恢复作业」
5. 租赁同步页把 `EX-SH-001` 小时数调到触发下一周期，验证同步即派单
6. 离线验证：DevTools → Network 切 Offline，外勤页仍可打开、填报并提交（进入发件箱），恢复网络后自动补传

## 主要 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/telemetry` | 租赁设备遥测 upsert（hours/faultCodes/siteId/坐标），同步后自动派单 |
| POST | `/api/dispatch/scan` | 全量扫描并对到期/故障设备批量派单 |
| GET | `/api/orders/:id` | 工单详情（含候选技师、时间线、报告） |
| POST | `/api/orders/:id/accept|enroute|arrive` | 技师状态流转 |
| POST | `/api/orders/:id/complete` | 完工上报（诊断/作业/用料/停机时长/照片 base64） |
| POST | `/api/orders/:id/confirm` | 客户确认 `{recovered, note}`（false 即返工） |
| POST | `/api/orders/:id/reassign` | 调度改派 |
